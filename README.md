All files were written in R-studio version 4.2 and R (version 4.4.1). 

After loading libraries and initializing a few universal variables you will be prompted to choose a dataset. Use the appropriate dataset before running.

Folders will automatically be generated in either "Results" or "data_analysis"

Inside that folder will be a folder with the date that the script was run, and the time. Within that is a folder named after the dataset used.

Inside that are 3 folders:

analysis: contains anovas or tukeyHSD analyses
tables: any tables generated, as well as outputs of the datasets after filters are run
visual: all graphs will be output here


Graphs will be output in pdf and png formats. They are output in a very high resolution, typically the equivalent of 2k or higher. This was so they could be put into slideshows presented in auditoriums without loss of detail, or into printable posters.
